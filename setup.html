Gym Manager setup

Before you start (2 minutes, in Supabase)

  1. Authentication → Sign In / Providers → Email: turn off "Confirm email", then Save.
  2. Authentication → URL Configuration: set Site URL to this app's address () so password-reset emails open the app.
  3. Keep your setup key ready. It's in README-FIRST.txt in the GYM folder on your computer, not on this website.

After setup, turn off "Allow new users to sign up" (Authentication → Sign In / Providers). Owner login keeps working and nobody else can create accounts.
